# 质量总评与审查范围

## 1. 结论

ChatLLM 是一套前后端分离的 **用户可配置 Agent + Agentic RAG 知识工作台**。架构已经从 Supabase 迁到本地 Docker Compose（PostgreSQL、Redis/BullMQ、MinIO、Python RAG、Milvus、Elasticsearch、Neo4j）。

整体判断：

- **综合评级：B+ / 预发布**
- **不是半成品脚手架**：配额、租约、fail-closed 检索、工具白名单、版本快照都已经落到代码和迁移里
- **最大短板不是缺功能，而是新旧路径没接好**：Agent Run 与 regenerate / continue / 删消息 / SSE 断线
- **带写工具（自定义 HTTP/MCP）的 Agent 暂不建议作为生产默认路径**

### 各维度评分（满分 10，主观）

| 维度 | 分 | 说明 |
|------|----|------|
| 架构设计 | 8.5 | 边界清晰，Agent 不是 DAG 外壳，RAG 是可选工具 |
| 安全边界 | 8.0 | JWT cookie、上传配额锁、DNS pin、AES-GCM、流协议校验 |
| RAG 效果（工程方向） | 8.0 | 混合检索 + 权威水合 + 证据不足拒答；效果上限取决于是否显式启用 rerank/graph |
| 测试体系 | 7.0 | 契约/单元强于 e2e；聊天生命周期 × Agent 几乎空白 |
| Agent 平台 | 6.5 | 配置面完整，聊天闭环不稳 |
| 前端体验 | 6.5 | 请求代际隔离好；首条发送、Continue 合并、断线恢复差 |
| 生产就绪 | 6.5 | 运维检查齐全；P1 未修前不宜默认开放写工具 |

## 3. 明确的强项（不要当缺陷去「修」）

这些是有意设计，整改时保持：

1. **Agent 不是工作流引擎。** 无 DAG/BPMN、无定时任务、无任意本地代码执行。见 `docs/agent-platform.md`「明确不包含」。
2. **Agentic RAG 是工具，不是外壳。** 未绑定 `agentic_rag` 的 Agent 不能访问知识库；普通聊天 RAG 开关独立。
3. **Run 使用已发布版本快照。** 编辑草稿不得改变进行中或已完成的 Run。
4. **SSE 断线不自动取消 Agent。** 用户必须显式停止或在运行记录里取消。这是文档承诺；真正的 bug 是断线后 **UI 不恢复轮询**，不是「断线应该杀掉 Run」。
5. **RAG 失败 fail-closed。** 检索不可用时停止生成，不编造无来源答案。
6. **证据不足拒答。** 检索已触发但无可用证据时跳过答案模型。
7. **自定义远端默认拒绝。** `AGENT_HTTP_ALLOWED_HOSTS` / `AGENT_MCP_ALLOWED_HOSTS` 空白 = 禁止所有自定义调用。
8. **内部 RAG token 信任 `user_id`。** RAG 默认绑 `127.0.0.1`，属于内网服务模型，不是越权绕过。

## 4. 产品能力地图（整改时对照）

### 已经具备、应保持可用

- GitHub OAuth + 本地账号、JWT access + refresh rotation
- Project Spaces、流式对话、消息分页/搜索、会话移动
- 多格式文档分片上传、MinIO、转换、完整性校验、失败重试
- 混合检索、图谱、评测中心、引用与 RAG trace
- Agent 中心 CRUD、发布、工具绑定、审批、Run/Step 持久化、聊天 SSE 时间线

### 文档已承诺但实现有缺口（必须整改或改文档）

| 承诺 | 缺口 | 文档 |
|------|------|------|
| SSE 断线或页面重载后从数据库恢复时间线 | 整页刷新可以；纯 SSE 断线不会进入恢复轮询 | `P1-SSE-RECOVER` |
| 取消或超时进入取消/失败，语义可区分 | 审批过期被记成普通 `agent_run_failed` | `P2-APPROVAL-EXPIRED` |
| 模型流不完整不得当成功 / 不得执行残缺工具 | `length` + tool_calls 仍可能执行 | `P1-LENGTH-TOOLS` |
| 删除知识后不应再被引用 | 缓存窗口内仍可能命中已删证据 | `P1-DELETE-CACHE` |

### 明确不做（不要开成整改项）

- 可视化节点 / DAG 工作流
- 定时或无人值守 Agent
- 进程重启后自动重放暂停中的工具副作用
- 本地 Shell / Python / 用户上传代码执行
- 未白名单的任意互联网或内网访问
- 为没有 Tool Calling 的模型模拟工具调用
- 多 Agent 协作、浏览器操控、电脑使用（Computer Use）

## 5. 风险摘要

| 风险 | 等级 | 用户可感知后果 |
|------|------|----------------|
| 再生/截断不取消旧 Agent Run | P1 | 幽灵助手消息、重复工具副作用 |
| 截断 tool call 仍执行 | P1 | 错误参数打到 HTTP/MCP |
| 删除后缓存仍引用旧文档 | P1 | 已删资料继续出现在回答里 |
| Continue 走 RAG | P1 | 续写变成乱检索或拒答 |
| 首次发送双发 / 创建失败无提示 | P1 | 重复会话、输入丢失 |
| Agent SSE 断线不恢复 | P1 | 时间线停住，以为 Run 死了 |
| Continue 合并消息导致删错 | P1 | 删掉历史段、留下续写段 |
